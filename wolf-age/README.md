# Nornloom: Wolf Age

The action game of Nornloom: the same world and the same myths as the card adventure, fought in
real time right on the map. Play it in the browser at [fight.nornloom.com](https://fight.nornloom.com).

| Every class, skill, spell, god, armour set and land, with its numbers | [HANDBOOK.md](HANDBOOK.md), the rules in full |
